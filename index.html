Social Media Auto Publisher

An independent, private automation tool for publishing the operator's own videos from a designated Google Drive folder to authorized social media channels.

How it works

The operator authorizes access to their YouTube channel using Google OAuth. The tool checks the connected channel, selects a video from the configured library, and uploads it with its title and description through YouTube API Services. A separate integration uses Meta's API for Instagram publishing.

This website is informational; it does not accept Google credentials or provide public account registration. The tool is not affiliated with Google, YouTube or Meta.
