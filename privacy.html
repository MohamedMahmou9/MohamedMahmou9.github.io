Privacy Policy

Effective: 26 November 2026.

Scope and data accessed

Social Media Auto Publisher is a private tool for the operator's authorized channels. It uses YouTube API Services to read channel identifiers and basic channel metadata for verification, and to upload selected videos with titles, descriptions and publication settings. It uses Google Drive API to list and download videos from a folder explicitly shared with its service account. It does not request access to Gmail, contacts or viewing history.

Use and sharing

Data is used to verify the target channel, perform authorized uploads and track publishing outcomes. Videos and associated metadata are sent to the intended platform. GitHub Actions processes the files and credentials to execute publishing; cron-job.org triggers the workflow using a separate GitHub credential. Google user OAuth tokens are not intended to be sent to cron-job.org. The operator does not sell Google user data or use it for advertising, profiling or unrelated purposes.

Storage and security

OAuth credentials are stored locally during setup and in private GitHub repository secrets for automated execution. Temporary video files are processed on the runner. Workflow logs and publication records may contain file names, channel identifiers, upload identifiers and status information. Access to these records should be limited to the operator. The operator is responsible for reviewing and removing or refreshing stored YouTube API data as required by applicable YouTube policies, and removing local or hosted credentials when they are no longer needed.

Revocation and deletion

Access can be revoked using Google's account security permissions. To request deletion of data retained by the tool, contact aliwmemo@gmail.com. The operator must stop affected workflows, remove credentials and delete relevant retained API data within the applicable policy deadlines. Published videos can be managed in YouTube Studio.

Third-party policies

Google processes data under its Privacy Policy. Use of Google API data is subject to the Google API Services User Data Policy, including applicable Limited Use requirements. Hosting providers and publishing platforms process data under their own policies.
